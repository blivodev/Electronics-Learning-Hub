# Choose Your Path

Pick **one board** and follow its track from beginner wiring to working projects. Each path is
self-contained and weaves the core electronics + microcontroller concepts in as you need them.

> 💡 **New to electronics?** Each path starts with a beginner tutorial, then adds components,
> circuits, and a real project you can build (breadboard → firmware → done).

| Track | What you'll do | Start |
|-------|----------------|-------|
| **Arduino (AVR)** | 8-bit AVR in C — the friendliest on-ramp to bare-metal micros | [Begin the Arduino path](arduino/index.md) |
| **ESP32 (Xtensa/RISC-V)** | Dual-core IoT SoC — Wi-Fi/Bluetooth, C/C++ and MicroPython | [Begin the ESP32 path](esp32/index.md) |
| **Microcontrollers (general)** | The core MCU concepts that apply to every board | [MCU path](mcu/index.md) |
| **Circuits & Schematics** | The electronics that make everything work | [Circuits path](circuits/index.md) |
