  <h1>Four guided tracks into electronics</h1>
  <p>This is where the hub turns from a reference library into a <b>guided curriculum</b>: each path is an ordered, beginner-to-advanced route that weaves the core electronics and microcontroller concepts in just when you need them. You don't read everything — you pick <b>one board</b> (or the pure electronics path) and follow its track to working projects.</p>
  <div class="s9-note">💡 <b>New to electronics?</b> Each path starts with a beginner tutorial, then adds components, circuits, and a real project you can build (breadboard → firmware → done). Start small, finish something that lights up, and build from there.</div>
</div>
