# ESP32 / IoT Mastery

> **Level:** 🟢 Beginner → ⚫ Advanced · **Est. time:** ~12 weeks · **Progress:** track your checkboxes below

**What you'll learn:** The ESP32 end-to-end — from first blink to Wi-Fi, BLE, MQTT, deep sleep, and production-grade IoT firmware.

**Who it's for:** Anyone who wants to build connected devices: sensors, home automation, and battery-powered IoT.

---

## How this path works

Follow the steps **in order**. Tick a checkbox when you finish a step.

**Legend:** 🟢 Beginner · 🟠 Intermediate · 🔴 Hard · ⚫ Advanced

---

## 🟢 Stage 1 — ESP32 basics (weeks 1-3)

- [ ] **1. ESP32 beginner** · 🟢 · 📝 [ESP32 Beginner](https://elecdocs.sektor9.dev/paths/esp32/beginner/) — the board, the IDE, and the first blink + serial.
- [ ] **2. ESP-IDF docs** · 🟢 · 📚 [ESP-IDF Programming Guide](https://docs.espressif.com/projects/esp-idf/en/latest/) — Espressif's official framework docs.
- [ ] **3. ESP32 technical reference** · 🟠 · 📚 [ESP32 Technical Reference Manual](https://www.espressif.com/sites/default/files/documentation/esp32_technical_reference_manual_en.pdf) — the hardware: GPIO, timers, and peripherals.

## 🟠 Stage 2 — Connectivity (weeks 4-7)

- [ ] **4. Wi-Fi on ESP32** · 🟠 · 📝 [Wi-Fi on ESP32](https://elecdocs.sektor9.dev/synthesized/esp32-advanced/) — connect to a network and run an HTTP server.
- [ ] **5. BLE basics** · 🟠 · 📝 [Bluetooth (BLE) Basics](https://elecdocs.sektor9.dev/synthesized/esp32-advanced/) — BLE GATT and broadcasting.
- [ ] **6. Internet of Things Projects with ESP32** · 🟠 · 📚 [IoT Projects with ESP32 (free PDF)](https://else.fcim.utm.md/pluginfile.php/90372/mod_resource/content/1/esp32%20programming.pdf) — sensor-to-cloud projects.
- [ ] **7. Andreas Spiess' ESP32 videos** · 🟠 · 🎬 [Andreas Spiess](https://www.youtube.com/@AndreasSpiess) — the definitive ESP32 channel: thoughtful, honest, deep.

## 🔴 Stage 3 — IoT engineering (weeks 8-10)

- [ ] **8. MQTT** · 🔴 · 📝 [MQTT basics (HiveMQ)](https://www.hivemq.com/blog/mqtt-essentials-part-1-introducing-publish-subscribe/) — the IoT protocol: brokers, topics, QoS.
- [ ] **9. ESP32 advanced: sleep** · 🔴 · 📝 [ESP32 Advanced (Wi-Fi/BLE/Deep Sleep)](https://elecdocs.sektor9.dev/synthesized/esp32-advanced/) — deep sleep, wake-on-timer, and battery life.
- [ ] **10. FreeRTOS on ESP32** · 🔴 · 📝 [RTOS on MCU (FreeRTOS)](https://elecdocs.sektor9.dev/synthesized/rtos-on-mcu/) — tasks, queues, and the real-time model under the ESP-IDF.

## ⚫ Stage 4 — Production (weeks 11-12)

- [ ] **11. Over-the-air updates** · ⚫ · 📝 [ESP-IDF OTA](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-reference/system/ota.html) — roll out firmware remotely.
- [ ] **12. TinyML on ESP32** · ⚫ · 📝 [TensorFlow Lite Micro on ESP32](https://www.tensorflow.org/lite/microcontrollers) — run a small model on-device.

---

## 🎯 Milestone project

Put it together: a **battery-powered ESP32 sensor node** that deep-sleeps, wakes on a timer, reads a sensor, publishes to an MQTT broker over Wi-Fi, and re-enters deep sleep — the complete IoT lifecycle.
