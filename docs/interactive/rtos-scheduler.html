⚙️ Interactive: FreeRTOS Task Scheduling

Watch three tasks with different priorities share one core. The highest-priority READY task always runs; lower ones wait. Click Step to advance time.

Model: preemptive priority scheduling (the FreeRTOS default on a single core). Each tick the scheduler picks the highest-priority task in the Ready state — task control blocks (TCBs) hold each task's state and stack pointer, and the context switch saves/restores registers.
